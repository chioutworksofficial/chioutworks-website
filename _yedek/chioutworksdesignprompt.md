## Your Task
Read ALL files in this project carefully. Understand the content, structure, purpose, and existing design. Then rebuild the entire website from scratch — professionally, completely, and perfectly.

---

## What You Must Do

### 1. Read First
- Read every HTML, CSS, JS file

### 2. Then Build — Complete Website

Rebuild the entire website with these sections:

**HERO**
- Strong, professional headline
- Clear subheading explaining what is offered
- Call-to-action button (e.g. "Contact Us", "Get Started")
- Clean, modern background (gradient or dark/light)

**NAVIGATION**
- Logo (top left)
- Menu links (smooth scroll)
- Mobile hamburger menu
- Sticky on scroll

**ABOUT / WHO WE ARE**
- Short, powerful description
- What makes this person/company unique
- Trust elements (experience, skills, languages)

**SERVICES**
- Cards for each service offered

**PORTFOLIO / WORK** (if applicable)

**TESTIMONIALS** (if applicable)
- Quote cards

**CONTACT**
- Contact form (name, email, message)
- Location info
- Social media links

**FOOTER**
- Logo
- Quick links
- Copyright
